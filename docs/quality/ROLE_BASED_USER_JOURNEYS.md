# Role-based user journeys

| Actor | Entry and decisions | Handoff or exception |
|---|---|---|
| Applicant | Start an application, edit structured profile, add evidence references, save and inspect review state. Respond to missing information in the profile. | A human reviewer records assessment and decision. Profile completeness grants no permissions. Formal post-draft submission is outstanding. |
| Admission staff | Open Applications and vetting, find the applicant by name or review state, read experience, education and evidence, investigate outstanding requests, resolve them and attest to the current profile version with a rationale. | New edits invalidate a stale version for approval. Verified private file inspection and specialized qualification rules remain outstanding. |
| Delivery administrator | Choose an authorized organization and create an engagement with its agreed objective. Create project and work packages, publish a sanitized opportunity, review interest, select and invite a professional. | Staffing activation remains subject to scoped acceptance. Some creation and invitation steps still use the local test harness. |
| Approved professional | Explore published opportunities, express interest, consider a formal invitation, accept it and open the assignment. Choose accepted work by name and submit a version for independent review. | Revision produces another version. Verified compensation and complete review history need further work. |
| Independent reviewer | Inspect the assigned work and decide whether a specific version meets criteria. Record review comments. | An approved version can reach the client. A revision returns to the professional. The reviewer screen still requires a deliverable reference. |
| Client member | Enter the authorized organization workspace, inspect progress, message the accountable team and review internally approved work. Accept the version or request changes. | Only accepted work advances to project completion. Billing and support require authoritative records and entitlements. |
| AI operations staff | Authorize bounded work under policy, inspect synthetic execution and submit its artifact to an independent human decision. | The tested executor is deterministic. Provider credentials, live evaluation and real cost verification are external gates. |

HubSpot owns commercial opportunities. BizPilot owns internal diagnostic evidence. Studio coordinates contracted delivery. Data Fellows owns client acceptance, staffing and handover throughout.
